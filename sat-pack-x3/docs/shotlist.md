## 1. Creative Concept — "1 + 2 = X3"

**Big Idea:** ทำให้โปรโมชันกลายเป็น "สมการ" ที่เด็กเตรียมสอบ SAT อ่านออกใน 1 วินาที

```
[ 1 แพ็กหลัก ]  +  [ คอร์สเสริม ]  +  [ คอร์สเสริม ]  =  คุ้ม X3
```

ทั้งวิดีโอคือการ "ประกอบสมการนี้ทีละชิ้น" — เปิดด้วยผลลัพธ์ (X3) → เลือกแพ็กหลัก 1 แพ็ก → คอร์สเสริมต่อเข้ามาทีละใบ (+1, +2) → สรุปว่าครบทั้ง Math และ R&W → พาไปที่เว็บ

**ทำไมเหมาะกับกลุ่มเป้าหมาย**
- **ภาษาของคนเตรียมสอบ:** นักเรียนสาย BBA/อินเตอร์คุ้นกับ Math, Desmos และ "การคิดเป็นสมการ" — การเล่าแบบสมการรู้สึก Smart ไม่ใช่โฆษณาลดราคาทั่วไป
- **ไม่สับสนแพ็กหลัก vs คอร์สเสริม:** ระบบภาพแยกสองชั้นชัดเจนตลอดเรื่อง (ดูข้อ 1.1) ทำให้ "X3" ถูกอ่านเป็น *1 แพ็ก + 2 คอร์สเสริม* ไม่ใช่ 3 แพ็ก
- **Scroll-stopping:** 0.0 s เปิดด้วย "คุ้ม X3" ขนาดเต็มจอ ไม่มี intro/logo ก่อน — Hook จบใน 3 วินาที
- **Conversion-first:** ข้อความหลักเพียง 1–2 ประเด็นต่อฉาก, URL ปรากฏ 2 ครั้ง (ฉาก 5 และ end card ค้างนาน ≥ 2 s), CTA บอกการกระทำที่ชัดเจน ("คลิกเลือกแพ็กที่ร่วมรายการ")

### 1.1 ระบบภาพกันสับสน (สำคัญที่สุด)

| องค์ประกอบ | แพ็กหลัก (Main Pack) | คอร์สเสริม (Bonus Course) |
|---|---|---|
| ป้ายหมวด | **"แพ็กหลัก"** | **"คอร์สเสริม · รับเพิ่ม"** |
| ขนาดการ์ด | ใหญ่ (กว้าง ~84% ของจอ 9x16) | เล็กกว่า (~70%), สูงครึ่งหนึ่งของการ์ดหลัก |
| สี | พื้นแดงเข้ม ตัวหนังสือขาว | พื้นดำ ขอบ/ป้ายสีทอง ตัวหนังสือขาว |
| ไอคอน | กระเป๋า/แพ็กซ้อนชั้น | ป้าย "+1" / "+2" สีส้ม-ทอง |
| ตำแหน่ง | อยู่บนสุดเสมอ | ต่อ "ใต้" การ์ดหลัก เหมือนติดมาด้วย |

กติกา: **ไม่ใช้คำว่า "แพ็ก" กับคอร์สเสริมเด็ดขาด** และไม่วางการ์ด 3 ใบขนาดเท่ากันเรียงแถวเดียว (จะดูเหมือนได้ 3 แพ็ก)

### 1.2 Look
- **สี:** ดำ `#0B0B0D` (พื้น) · แดง `#E10600` (แบรนด์/แพ็กหลัก) · ขาว `#FFFFFF` · ส้ม `#FF7A00` และทอง `#F5B800` เฉพาะจุดโปรโมชัน (X3, +1/+2, ปุ่ม CTA) — ค่าสีจริงยืนยันจากเว็บแบรนด์ในขั้น gather
- **ฟอนต์ (2 ตัวเท่านั้น):** Display = **Kanit ExtraBold/Black** (ไทย+ละติน, หนา อ่านง่ายบนมือถือ) · UI = **IBM Plex Sans Thai SemiBold** (ชื่อคอร์ส, URL) — หากแบรนด์มีฟอนต์ทางการ ให้ใช้ของแบรนด์แทน
- **กราฟิกสื่อ SAT:** กระดาษคำตอบ/bubble sheet, เส้นกราฟ Desmos (พาราโบลา), ไฮไลต์ปากกาเน้นคำ (Grammar), progress bar/score meter, เส้นกริดกระดาษกราฟจาง ๆ เป็นพื้นหลัง
- **ไม่มีราคา, ส่วนลด, วันหมดเขต, คำว่า "ฟรี"** หรือเงื่อนไขอื่นที่ไม่ได้ระบุในบรีฟ

## 4. Motion Direction

**จังหวะรวม:** ฉาก 1–2a เร็ว แรง (cut ทุก 3–4 beats, spring แรง, shake สั้น) → ฉาก 2b–4 ช้าลง จัดวางนิ่ง ให้เวลาอ่าน (ข้อความหลักค้าง ≥ 1.5 s ก่อนเปลี่ยน) → ฉาก 5 ปิดด้วย impact แล้วนิ่ง

- **Kinetic type:** ข้อความเข้าด้วยทิศทางมีเหตุผล (ตกลงมาวาง, สไลด์เข้า, stamp) ไม่ใช้ fade-in ลอย ๆ; ตัวเลข "1", "2", "3", "X3" เด้งแบบ squash-and-settle; ข้อความยาว (ชื่อคอร์ส) เข้าเป็นบล็อกเดียว ไม่แตกทีละตัวอักษร เพื่อให้อ่านทัน
- **Course Card:**
  - แพ็กหลัก: เข้าจากด้านข้าง สวนกันสองใบ, มีน้ำหนัก (spring overshoot ~6%), เงาตกเข้ม
  - การเลือก: ✓ กระโดดระหว่างการ์ด การ์ดที่ถูกเลือกยกขึ้น 4% อีกใบหรี่ 70%
  - คอร์สเสริม: พุ่งขึ้นจากล่างจอแล้ว "ล็อก" ใต้การ์ดหลัก (snap + shake 2 เฟรม) ป้าย +1/+2 stamp ทีหลัง ¼ beat
- **Transitions (ทุกการตัดมีวัตถุพาไป ไม่มีเฟรมว่าง):**
  - 1→2: whip-pan แนวตั้ง ทั้งสองภาพอยู่บนจอพร้อมกัน
  - 2→3: การ์ดแพ็กสองใบ morph รวมเป็นใบเดียว "SAT Pack ที่ร่วมรายการ"
  - 3→4: match cut — การ์ดคอร์สเสริมแต่ละใบขยายกลายเป็นฝั่ง Math / R&W
  - 4→5: สองฝั่งพับเข้ากลางเป็น X3 (ใช้ full flash ครั้งเดียวที่นี่)
- **Zoom/push:** ใช้ log-space (ความเร็วคงที่) push ช้า 3–5% ตลอดฉาก 2b–4 ให้ภาพไม่ตาย
- **ห้าม:** particle burst ทั่วไป, glow บนตัวหนังสือ, blur หนักบนข้อความ, flash ทุก cut

## 5. Audio Direction

- **ดนตรี:** 128 bpm, energetic trap / future-bass ที่ "สะอาด" (ไม่มีเสียงร้อง) — ฉาก 1 เปิดด้วย drop เต็ม, ฉาก 2b–3 ลดเหลือ drums+bass ให้ SFX การ์ดเด่น, riser ฉาก 4, drop สุดท้ายที่ CTA แล้ว tail จบพอดี 18.75 s ; ถ้าใช้เพลง stock ให้เลือกที่ระบุว่าใช้โฆษณา Meta ได้
- **SFX (ล็อกบน beat grid):** impact/sub-drop (X3), whoosh (whip), click-snap (การ์ดต่อ), pop (ตัวเลข), tick (✓ เลือกแพ็ก), slam+chime สว่าง (+1/+2 — เสียง "ได้ของเพิ่ม"), highlighter swipe (R&W), pencil/graph scribble (Desmos), coin-ding (ตัวนับ 3), riser→impact (CTA)
- **ไม่มี Voice-over:** ~85% ดูแบบปิดเสียงบน Feed — ข้อความบนจอต้องเล่าเรื่องได้ครบ
- **Mix:** -14 LUFS integrated, -1 dBTP; SFX อยู่เหนือดนตรี ~3 dB ในช่วงการ์ด
